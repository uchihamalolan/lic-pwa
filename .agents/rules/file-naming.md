# Strict Kebab-Case File Naming Rule

Use **kebab-case** for ALL files in the codebase without exception:
- Component files: `claims-table.tsx`, `agent-card.tsx`, `app-header.tsx`
- View files: `dashboard-view.tsx`, `upload-view.tsx`
- Hooks: `use-claims.ts`, `use-agent-filter.ts`
- Utility/Type/Store files: `lic-parser.ts`, `claim-types.ts`, `claims-store.ts`

Do NOT use PascalCase (e.g. `ClaimsTable.tsx`) or camelCase for any source files.
